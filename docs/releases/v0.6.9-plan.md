# Unlimited Skills v0.6.9 — Governed Fleet Foundation

Released: 2026-08-05

Unlimited Skills 0.6.9 turns the public client into the stable pre-1.0
foundation for governed skill delivery. The local MIT core still works
offline, while organizations that opt into Business or Enterprise Fleet can
receive signed desired state, activate approved packs through runtime-native
adapters, and return server-verifiable delivery evidence.

## New features

- **Security-gated installation:** supported local and managed install paths
  run NVIDIA SkillSpector before skill files are copied. Incomplete scans and
  unavailable scanners fail closed.
- **Fleet Wire Contract v1:** agent identities, immutable desired state,
  scoped payload downloads, activation receipts, drift evidence, retry, halt,
  and higher-epoch rollback share one frozen public contract.
- **Runtime adapters:** Codex, Claude Code, OpenClaw, and Hermes can reconcile
  signed multi-pack inventories without exposing prompts, source code, private
  skill bodies, or agent outputs to the dashboard.
- **Local business context:** an explicitly configured owner-controlled
  provider may add bounded, cited reference data, not instructions, to the
  selected skill card.

## Improvements

- Identical managed skills from multiple approved packs are deduplicated by
  exact skill-tree digest. Same-name skills with different content remain a
  fail-closed collision.
- Read-only managed skill mirroring is idempotent, so health reconciliation
  does not rewrite unchanged files or create false drift.
- Runtime-startup latency remains `ACTIVATION_PENDING` and can finish from a
  later attestation without reinstalling the inventory.

## Release and trust boundaries

- The public core never names or depends on a private knowledge system.
- In this contract, the Stop hook never submits prose. It can forward only an explicit bounded
  signed completion receipt supplied by a trusted host.
- A committed record whose index or visibility proof failed is not reported as accepted.
- The current file-first backend remains supported.
- No deletion, replacement, or migration of `library/local` is part of this
  release.
- Business and Enterprise Fleet is a separately operated hosted capability;
  it is not required for local search, quickstart, indexing, or security scans.
- This is a pre-1.0 release, not a production SLA for every deployment.

## Install

```bash
python -m pip install --upgrade "unlimited-skills==0.6.9"
unlimited-skills --version
unlimited-skills quickstart
```

For vector retrieval and the local warm daemon:

```bash
python -m pip install --upgrade "unlimited-skills[all]==0.6.9"
```

## Publication acceptance

The release workflow must build wheel and sdist once, run `twine check`, test
the exact wheel in clean environments, verify the frozen v0.6 contracts,
publish by PyPI Trusted Publishing, confirm the public artifact hashes and
clean-install behavior, and only then create GitHub release `v0.6.9` at the
exact selected `main` SHA.

There are no intentional breaking Fleet Wire v1 changes in this release.
