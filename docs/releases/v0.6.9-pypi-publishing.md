# PyPI Trusted Publishing for v0.6.9

Unlimited Skills 0.6.9 is published only through the repository's manual
GitHub Actions workflow and PyPI Trusted Publishing.

| PyPI field | Required value |
| --- | --- |
| Project/package name | `unlimited-skills` |
| Owner | `AI4sale` |
| Repository | `unlimited-skills` |
| Workflow filename | `publish-pypi.yml` |
| Environment | `pypi` |

Dispatch inputs:

```yaml
version: 0.6.9
expected_sha: <exact current main SHA>
confirm_pypi_publish: publish unlimited-skills 0.6.9 to PyPI
```

The workflow checks that `expected_sha` is the current remote `main`, builds
and tests the exact artifacts, publishes with OIDC, verifies public PyPI hashes
and a clean install, and only then creates GitHub release `v0.6.9` at the same
SHA.

No `PYPI_TOKEN`, `TWINE_PASSWORD`, `TWINE_USERNAME`, or local `.pypirc` is used.
Do not upload the distribution manually. If PyPI accepts `0.6.9` but the
post-publication verifier fails, fix forward with a new version; never replace
an immutable PyPI artifact.
